Passo a passo: Webhooks e uso em aplicações

1 Cadastrar um novo webhook

  1. Na seção Webhooks abaixo, localize a sessão desejada (ex.: o sessionId do WhatsApp que você usa).
  2. Clique em + Add webhook e informe a URL do seu servidor (ex.: https://sua-app.com/webhook). A URL deve ser acessível pela internet (HTTPS recomendado).
  3. Marque os eventos que deseja receber: message (mensagens), connection (conexão/desconexão), qr (QR Code).
  4. Clique em Add Webhook. O webhook passará a receber POSTs nessa URL sempre que o evento ocorrer.

Você também pode registrar via API (requer token JWT):

POST /session/{sessionId}/webhooks
Authorization: Bearer <seu_token>
Content-Type: application/json

{
  "url": "https://sua-app.com/webhook",
  "events": ["message", "connection"]
}

2 Enviar mensagens pela API (aplicações de terceiros)

Use o token JWT obtido no login. Todas as requisições devem incluir Authorization: Bearer <token>.

Mensagem de texto

POST /session/{sessionId}/message/text
Authorization: Bearer <token>
Content-Type: application/json

{
  "to": "5511999999999",
  "message": "Olá! Mensagem enviada pela API."
}

O número pode ser com ou sem @s.whatsapp.net; a API normaliza automaticamente.

Mensagem com anexo (imagem, vídeo, áudio, documento)

POST /session/{sessionId}/message/media
Authorization: Bearer <token>
Content-Type: application/json

{
  "to": "5511999999999",
  "fileBase64": "<conteúdo_do_arquivo_em_base64>",
  "caption": "Legenda opcional",
  "filename": "documento.pdf",
  "mimetype": "application/pdf"
}

Campos obrigatórios: to, fileBase64. Opcionais: caption, filename, mimetype (ex.: image/jpeg, video/mp4, audio/ogg).

3 Ouvir mensagens dos usuários via webhook

Quando você cadastra um webhook com o evento message, seu servidor recebe um POST na URL configurada sempre que chegar uma mensagem (ou atualização) na sessão.

  • Método: POST
  • Headers enviados: Content-Type: application/json, X-Event-Type: message, X-Session-ID: <sessionId>
  • Corpo (JSON): event, sessionId, timestamp, data

Exemplo de payload para evento message:

{
  "event": "message",
  "sessionId": "uuid-da-sessao",
  "timestamp": "2025-02-06T12:00:00.000Z",
  "data": {
    "messages": [
      {
        "key": {
          "remoteJid": "5511999999999@s.whatsapp.net",
          "fromMe": false,
          "id": "MSG_ID"
        },
        "message": {
          "conversation": "Texto enviado pelo usuário"
        },
        "messageTimestamp": "1234567890"
      }
    ],
    "type": "notify"
  }
}

Em data.messages vêm as mensagens (Baileys). Para texto use message.conversation; para mídia, message.imageMessage, message.videoMessage, etc. Responda com status 2xx para o servidor considerar entrega ok.

Exemplo em Node.js (receber e processar):

app.post('/webhook', (req, res) => {
  const event = req.headers['x-event-type'];
  const sessionId = req.headers['x-session-id'];
  const { event: e, sessionId: sid, timestamp, data } = req.body;

  if (event === 'message' && data?.messages) {
    for (const msg of data.messages) {
      if (msg.key?.fromMe) continue;
      const text = msg.message?.conversation || msg.message?.extendedTextMessage?.text;
      const from = msg.key?.remoteJid;
      console.log(`[${sessionId}] De ${from}: ${text}`);
      // Responder via API: POST .../session/${sessionId}/message/text
    }
  }
  res.status(200).send('OK');
});
